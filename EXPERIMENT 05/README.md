# Experiment 5 - HTTP Methods and Routes

## Aim

To create routes that handle GET, POST, PUT and DELETE requests.

## HTTP Methods

GET:
Used to retrieve data.

POST:
Used to add new data.

PUT:
Used to update existing data.

DELETE:
Used to delete data.

## Routes

GET /students

POST /students

PUT /students/:id

DELETE /students/:id

## How to Run

node server.js

Server will run on:

http://localhost:3000

## Testing

GET can be tested using a browser.

POST, PUT and DELETE can be tested using Postman or Thunder Client.

## Result

All four HTTP methods were successfully implemented.

## Conclusion

GET, POST, PUT and DELETE are commonly used for performing CRUD operations through HTTP APIs.
