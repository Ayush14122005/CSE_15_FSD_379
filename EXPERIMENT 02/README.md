# Experiment 2 - File CRUD Operations

## Aim
To perform Create, Read, Update and Delete operations on files using the Node.js fs module.

## CRUD Operations

Create:
fs.writeFileSync()

Read:
fs.readFileSync()

Update:
fs.appendFileSync()

Delete:
fs.unlinkSync()

## How to Run

node app.js

## Result

The program successfully creates, reads, updates and deletes a file.

## Conclusion

The Node.js fs module is used to perform file system operations.
